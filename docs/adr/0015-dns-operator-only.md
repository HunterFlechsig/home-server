# DNS Filter is Operator-only while the Cox Gateway is in charge

The CGM4140COM does not give us DHCP DNS, and Cox does not let us turn its DHCP off. Bridging it would move household Wi-Fi onto a router we do not have and is out of scope for standing up the Laptop Host. AdGuard Home still runs in the DNS Guest; only Operator devices are configured to use it. Household-wide filtering waits until there is a router we control.
